# 快速入门指南

## 立即开始

### 1. 编译运行

```bash
cd invoice_rust
cargo run --release
```

或直接运行编译好的程序：

```bash
./target/release/invoice-extractor
```

### 2. 使用流程

#### 步骤 1: 配置

在界面左侧配置区域填写：

- **发票目录**: 点击 📁 选择包含发票PDF的文件夹
- **购买方关键词**: （可选）输入公司名称关键词
- **输出文件**: （可选）自定义Excel文件保存位置

#### 步骤 2: 开始处理

点击绿色的 **🚀 开始识别** 按钮

#### 步骤 3: 查看进度

处理开始后，您将立即看到：

## 配置文件

首次运行会自动生成 `config.toml`：

```toml
# 线程池大小（1-128）
thread_pool_size = 32
```

### 推荐配置

根据您的电脑配置调整：

```toml
# 低配机器（4核以下）
thread_pool_size = 8

# 中配机器（4-8核）
thread_pool_size = 16

# 高配机器（8核以上）
thread_pool_size = 32
```

修改后重启程序生效。

## 常见问题

### Q: 如何查看进度？

**A**: 处理开始后，配置区域会自动显示进度条和完成百分比。

### Q: 为什么进度条更新很快？

**A**: 使用了多线程并行处理，32个线程同时工作，所以速度很快。

### Q: 可以取消处理吗？

**A**: 当前版本暂不支持取消，一旦开始会处理完所有文件。

### Q: 如何调整线程数？

**A**: 编辑可执行文件同目录下的 `config.toml`，修改 `thread_pool_size` 值。

### Q: 日志太多怎么办？

**A**: 点击日志区域右上角的"清除"按钮可以清空日志。
