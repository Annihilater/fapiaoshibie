# 更新日志

## [0.3.0] - 2026-01-12

### 新增功能

- ✨ **实时进度显示**: 处理过程中显示实时进度信息
  - 即时统计需要处理的文件总数
  - 可视化进度条动态显示处理进度
  - 实时显示完成数量和总数
  - 动态更新完成百分比
  - 批量日志更新，每10个文件输出一次进度
  
- 🎯 **非阻塞UI**: 多线程处理确保界面始终响应
  - 处理任务在后台线程池运行
  - 通过消息通道实时传递进度信息
  - 主界面保持流畅，不会卡顿
  - 用户可以随时查看日志和进度

### 技术改进

- 使用 `mpsc::channel` 实现进度消息传递
- 使用 `AtomicUsize` 实现线程安全的计数器
- 新增 `ProgressMessage` 枚举类型
- 优化 `process_invoices_with_progress` 函数支持进度回调

### 用户体验提升

- 处理前：即时显示文件总数，让用户心里有数
- 处理中：实时进度条和百分比显示，方便估算剩余时间
- 处理中：批量日志更新，让用户感受到快速处理
- 整个过程：界面始终响应，可以随时查看日志

### 性能优化

- 批量日志输出策略，减少UI刷新频率
- 原子计数器实现无锁并发计数
- 非阻塞消息接收，保持UI流畅

## [0.2.0] - 2026-01-12

### 新增功能

- ✨ **多线程并行处理**: 添加基于 rayon 的多线程并行处理功能，大幅提升处理速度
  - 默认使用 32 个线程并行处理发票文件
  - 可通过配置文件调整线程数（范围 1-128）
  
- 📝 **配置文件系统**: 支持通过 TOML 配置文件自定义程序行为
  - 首次运行自动生成 `config.toml`
  - 配置文件位于可执行文件同目录
  - 提供 `config.example.toml` 配置示例

- 🔧 **线程数显示**: GUI 界面实时显示当前使用的线程数
  - 配置区域右上角显示线程数
  - 处理开始时日志输出线程数信息

### 技术改进

- 添加 `rayon` 依赖用于并行处理
- 添加 `serde` 和 `toml` 依赖用于配置管理
- 新增 `config.rs` 配置管理模块
- 优化文件处理流程，支持批量并行处理

### 性能提升

- 多个发票文件同时处理，充分利用多核 CPU
- 大量文件场景下处理速度提升显著（取决于 CPU 核心数）

### 文档更新

- 更新 README.md，添加配置说明
- 新增 CHANGELOG.md 更新日志
- 新增 config.example.toml 配置示例
