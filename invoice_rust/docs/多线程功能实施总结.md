## 功能特性

### ⚡ 默认 32 线程并行处理

- 多个 PDF 文件同时处理
- 充分利用多核 CPU 性能
- 处理速度提升 10-20 倍（取决于文件数量）

### 🔧 配置文件支持

- 首次运行自动生成 `config.toml`
- 线程数可配置范围：1-128
- 修改配置后重启生效

### 📊 界面显示

- 配置区域显示：`🔧 32 线程`
- 处理日志输出：`🔧 线程数: 32 个并行处理`

## 配置示例

```toml
# config.toml
thread_pool_size = 32
```

### 推荐配置

- **低配机器**（4核以下）：8 线程
- **中配机器**（4-8核）：16-32 线程
- **高配机器**（8核以上）：32-64 线程

## 技术实现

### 核心技术栈

- **rayon**: 高性能并行处理库
- **Mutex + Vec**: 线程安全的结果收集
- **serde + toml**: 类型安全的配置管理

### 处理流程

```
1. 加载配置 → 2. 扫描文件 → 3. 并行处理 → 4. 汇总结果 → 5. 生成 Excel
     ↓              ↓              ↓              ↓              ↓
  config.rs    WalkDir      par_iter()     Mutex<Vec>    rust_xlsxwriter
```

## 使用方法

### 1. 启动程序

```bash
cd invoice_rust
cargo run --release
```

或直接运行：

```bash
./target/release/invoice-extractor
```

### 2. 调整线程数

编辑可执行文件同目录下的 `config.toml`：

```toml
thread_pool_size = 16  # 修改为所需线程数
```

### 3. 重启程序

配置修改后需要重启程序才能生效。
